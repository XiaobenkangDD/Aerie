# 收藏到 Aerie（未打包的 Chrome 扩展）

把网页上的图片交给本机正在运行的 Aerie。扩展不打包、不上架。Aerie 只监听 `127.0.0.1`，请求要带库里的 token。

## 加载

1. 用 Chrome 打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选中这个目录（`extensions/aerie-chrome`）。
4. 在 Aerie 里打开一个库，点侧栏底部的「收藏与识别」，复制端口和 token。
5. 点浏览器工具栏里的扩展图标，把端口和 token 填进去，保存。

## 使用

在网页图片上右键，选「收藏到 Aerie」。

Aerie 会把图片下载到库的 `inbox`，再走原来的导入。页面地址写进条目的来源，页面标题写进备注。库必须是打开的，否则扩展连不上。
